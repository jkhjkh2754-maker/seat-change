# 우리 반 자리 만들기

교실 모양과 학생 명단을 입력해 무작위로 자리를 배치하고, 교환한 최종 결과를 한글 PDF로 다운로드하는 한국어 웹사이트입니다. **1·2·4·5단계를 구현·검증했습니다.** 사용자 요청에 따라 짝 지정과 3단계 배치 조건(고정석·인접 금지·필수/선호 구역)은 제외했습니다.

HTML·CSS·JavaScript와 프로젝트에 포함한 PDF 자원으로 동작합니다. 별도 빌드나 백엔드는 없으며 GitHub Pages에서 실행 가능한 구조입니다. **공개 배포 완료:** https://jkhjkh2754-maker.github.io/seat-change/ — [배포 안내](DEPLOYMENT.md)

## 내 컴퓨터에서 실행하기

1. GitHub 저장소의 Code → Download ZIP을 눌러 압축을 풉니다.
2. Python 3가 설치된 컴퓨터에서 압축을 푼 폴더를 터미널로 엽니다.
3. `python3 -m http.server 8000`을 실행합니다. Windows에서 python3 명령이 없다면 `py -m http.server 8000`을 사용합니다.
4. 브라우저 주소창에서 `http://localhost:8000`을 엽니다.
5. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

ES 모듈과 글꼴 파일 읽기를 사용하므로 index.html을 두 번 클릭하는 대신 위 방법으로 실행하세요. Node.js도 설치되어 있으면 `npm start`를 사용할 수 있지만 Python 3는 여전히 필요합니다. 사이트 사용을 위한 npm 패키지 설치는 필요 없습니다.

## 사용 순서

1. **교실 만들기:** 행·열을 설정합니다. 각각 1~12, 전체 120석까지 지원합니다. 배치 전 좌석을 누르면 제외·복원됩니다.
2. **명단 준비:** 번호 생성·직접 입력·CSV 중 하나를 선택합니다. 미리보기 표에서 번호를 확인하고 이름을 수정한 뒤 **이 명단 확정**을 누릅니다. 미리보기는 확정 전까지 현재 명단을 변경하지 않습니다.
3. **배치:** 전체 공개 또는 한 자리씩 공개를 선택하고 **자리 배치 시작**을 누릅니다. 5초 카운트다운 후 결과가 준비됩니다. 음악은 음소거하거나 볼륨을 조절할 수 있습니다. 취소 버튼 또는 Escape로 중단하면 이전 결과를 유지합니다.
4. **공개·교환:** 한 자리씩 공개에서는 좌석을 눌러 공개합니다. 공개된 좌석 두 개를 차례로 누르면 교환됩니다. 빈자리 이동, 마우스 드래그, 실행 취소·다시 실행도 가능합니다. 숨긴 결과를 보려면 결과 다시 보기를 누릅니다.
5. **PDF:** 제목과 A4 가로·세로를 고르고 PDF 파일 다운로드를 누릅니다. 현재 학생/교사 보기 방향과 수동 교환 결과가 반영됩니다. 결과가 숨겨져 있어도 PDF에는 전체 결과가 포함됩니다. 큰 좌석이 필요하면 여러 페이지 옵션을 선택합니다.

배치 후 교실 편집 버튼을 누르거나 교실 설정을 적용하거나 새 명단을 확정하면 기존 결과와 교환 이력이 초기화됩니다. 보기 방향·큰 글씨 전환은 실제 배치를 바꾸지 않습니다.

## 명단 입력 형식

- 번호 생성: 시작·종료번호, 제외 번호(쉼표 또는 공백 구분). 한 번에 최대 120개 번호를 생성하며 `001` 같은 앞자리 0을 보존합니다.
- 직접 입력: 한 줄에 이름만 또는 `001 김하늘`, `001<TAB>김하늘`. 번호 없는 이름에는 겹치지 않는 번호를 자동 부여합니다. 미리보기에서 번호를 확인하고 이름을 수정하세요.
- CSV: 첫 줄 `번호,이름` (`학번,이름`도 호환) 또는 `number,name`. UTF-8(권장), EUC-KR/CP949를 지원합니다. 최대 1MB, 120명입니다. 한글이 깨지면 인코딩을 바꾸고 다시 읽으세요.

번호는 문자열로 처리합니다. 중복 번호·빈 이름·빈 명단·좌석 부족은 확정을 막고 설명합니다. 동명이인은 서로 다른 번호로 구별하며 좌석이 더 많으면 빈자리로 남습니다.

## 모바일과 키보드

휴대전화에서는 세로 화면으로 설정 후 교실을 확인합니다. 넓은 교실은 **좌석 영역만 좌우로 밀어** 볼 수 있습니다. 터치 드래그 대신 공개된 두 좌석을 차례로 눌러 교환하는 방법을 권장합니다. 전체화면이 지원되지 않으면 큰 글씨 보기를 사용하세요.

- Tab / Shift+Tab: 입력 칸·버튼 이동
- 좌석에서 방향키: 화면에 보이는 방향으로 이동, 배치 후 제외 좌석은 건너뜀
- Home / End: 현재 화면 행의 처음·끝, Ctrl과 함께 누르면 전체 처음·끝
- Enter / Space: 좌석 제외·복원, 공개 또는 교환 대상 선택
- Escape: 교환 대상 선택 해제. 카운트다운 중에는 배치 취소
- 카운트다운 중 Tab은 음소거·볼륨·취소 사이를 이동합니다. 종료·취소 후 시작 버튼으로 초점이 돌아옵니다.

## 데이터와 PDF

명단·조건 없는 배치 결과·실행 취소 기록은 현재 페이지 메모리에만 유지합니다. 새로고침하거나 창을 닫으면 초기화됩니다. 브라우저 저장소·쿠키·URL 쿼리·서버·분석/광고 도구에 저장하거나 명단을 전송하지 않습니다. CSV는 처음 명단을 입력하는 수단이며 백업 파일은 지원하지 않습니다. 사용자가 요청한 PDF만 다운로드 파일로 남습니다.

PDF는 브라우저에서 텍스트와 도형으로 생성합니다. 한글 글꼴을 포함하고 칠판·교탁·학생 번호·빈자리·제외 좌석을 표시합니다. 학생 좌석에는 이름이나 좌석 코드 없이 번호 하나만 표시합니다. 설정 패널·버튼은 출력하지 않습니다. 긴 이름은 줄바꿈·크기 조절하며, 읽기 좋은 크기로 담을 수 없는 입력은 방향 변경·분할·입력 수정 안내와 함께 오류로 처리합니다. 지원하지 않는 문자(일부 이모지 등)도 오류로 알립니다. 일반 학급은 한 페이지, 120석 등 큰 교실은 필요에 따라 분할하세요.

음악은 Web Audio에서 직접 합성한 점차 빨라지는 아르페지오입니다. 외부 음원·음악 API를 사용하지 않습니다. 재생이 거부되면 무음으로 진행합니다. 무작위 배치가 매번 이전과 다르거나 모든 배치에서 균등하게 추출된다고 보장하지 않습니다.

## 검증과 지원 범위

[TESTING.md](TESTING.md)에 자동 확인 항목과 미확인 항목을 기록했습니다. Chromium에서 PC·모바일 크기와 터치 입력을 검증했습니다. 실제 Samsung Internet·iPhone·Firefox·스크린리더·프린터는 아직 확인하지 않았습니다. 휴대전화 실기기에서의 오디오·전체화면·PDF 저장 방식은 브라우저와 기기에 따라 확인이 필요합니다.

개발용 핵심 테스트는 Node.js 20 이상에서 `npm test`입니다. 전체 브라우저 검증은 개발 환경에 Playwright·Chromium·Python 3·Poppler(pdftotext)가 있을 때 `npm run test:browser`로 실행합니다. Playwright가 없다면 `npm install --no-save playwright`로 준비합니다. Chromium 실행 경로가 /usr/bin/chromium과 다르면 CHROMIUM_PATH 환경변수를 지정하세요. 테스트는 로컬 8765 포트를 차례로 사용하며 출력 파일은 /tmp와 무시되는 preview-*.png에 만듭니다. 이 도구들은 사이트 이용자에게 필요하지 않습니다.

## 교실 만들기 안내와 배포 파일 버전

교실 만들기를 누르면 버튼 바로 아래에 적용된 행·열·전체 좌석 수가 표시됩니다. 같은 크기를 적용해도 확인 안내가 나옵니다. 입력 오류도 같은 위치에 표시하며 기존 교실은 유지합니다. 모바일에서는 만든 교실 확인하기 링크로 미리보기로 이동할 수 있습니다.

사이트 HTML·JavaScript·CSS를 수정한 뒤에는 `npm run version:assets`를 실행하고 변경된 파일을 함께 커밋하세요. 내용으로 계산한 동일한 버전을 진입 스크립트와 의존 모듈 URL에 붙여, 브라우저에 남은 이전 모듈과 새 모듈이 섞이는 문제를 줄입니다. 실행·배포에 별도 빌드는 필요 없습니다. 이미 이전 페이지를 열어 둔 경우 새로고침하거나 공개 주소를 다시 열어 새 버전을 불러오세요.

학번을 직접 수정하는 입력 칸은 제거했습니다. 번호는 미리보기에서 읽기 전용으로 확인하며, 배치 결과와 PDF에는 동일한 번호 하나만 표시합니다. 이름은 명단 확인용으로만 사용합니다.
