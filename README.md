# 우리 반 자리 만들기

교사용 한국어 자리 배치 도구. 현재 **4단계** 구현 (3단계는 사용자 요청으로 제외)입니다. 외부 라이브러리 없이 HTML/CSS/JavaScript를 사용해 설치·빌드 없이 GitHub Pages에서 실행 가능한 구조입니다. 공개 배포 설정은 아직 하지 않았습니다.

## 실행

Python 3 설치 후 이 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. Node.js가 있으면 `npm start`도 같은 명령을 실행합니다. ES 모듈을 사용하므로 파일을 직접 두 번 클릭하는 대신 이 방법으로 여세요. 별도 빌드는 없습니다. 자동 검증은 Node.js 20 이상에서 `npm test`입니다.

## 1단계 확인 방법

1. 행·열을 입력하고 교실 만들기를 누릅니다. 각각 1~12, 전체 120석 이내입니다.
2. 좌석을 눌러 제외·복원합니다. 통로 입력에 `2, 4`를 넣고 적용합니다. 통로는 좌석 수에 포함되지 않습니다.
4. 번호 생성, 직접 입력, CSV 중 하나를 선택하고 미리보기를 만듭니다. 표에서 수정 후 명단 확정을 누릅니다.
5. 기본 검증 버튼으로 좌석 부족·빈 명단·빈 이름·중복 학번을 확인합니다. 동명이인은 학번 또는 구분 번호로 구별합니다.
6. 교사/학생 보기 전환 시 칠판 위치와 좌석 ID를 비교합니다. 교사 보기는 180도 회전한 시점입니다.

직접 입력은 한 줄에 이름만 또는 `학번 이름`, `학번<TAB>이름`입니다. 공백이 있는 전체 이름은 미리보기에서 수정할 수 있습니다. CSV 첫 줄은 `학번,이름` 또는 `number,name`이며 인코딩은 UTF-8(권장), EUC-KR/CP949를 지원합니다. 한글이 깨지면 인코딩을 바꿔 다시 읽으세요. 앞자리 0을 보존하며 최대 120명, CSV 1MB를 지원합니다.

## 데이터와 자원

명단·설정은 메모리에만 있습니다. 새로고침하면 초기화됩니다. 브라우저 저장소, 쿠키, URL 저장, 서버 전송, 분석 도구를 사용하지 않습니다. CSV는 최초 명단 입력 용도입니다. 사용자 입력은 텍스트와 입력 필드로만 표시합니다.

화면에는 운영체제 기본 글꼴을 사용하며, PDF용 글꼴·라이브러리는 프로젝트에 포함합니다. 운영체제 기본 글꼴과 직접 작성한 CSS를 사용합니다. 참고 사이트의 코드·이미지·음원은 복제하지 않았습니다. 향후 PDF 글꼴과 음악 자원은 해당 단계에서 라이선스와 출처를 기록합니다.

## 다음 단계

5. 모바일·키보드 및 전체 검증

각 단계는 별도 승인 후 진행합니다. 고정석·인접 금지·필수·선호 구역 등 배치 조건은 사용자 요청으로 구현 대상에서 제외했습니다. 로그인·영구 저장·불러오기·배치 이력·동기화는 구현하지 않습니다.

## 이번 단계 검증 결과

- 핵심 입력 검증: 번호 생성·제외·앞자리 0, 직접 입력, CSV BOM·따옴표·개행, 중복 학번·동명이인, 40명 명단, 좌석 상한 검사 통과.
- Chromium 실제 브라우저: 30명 확정, 좌석 제외, 보기 전환, 통로, CSV 확정, 중복 학번 차단, HTML 입력을 텍스트로 처리, 새로고침 초기화, 390px 모바일 문서 너비 검사 통과.
- 데스크톱과 모바일 스크린샷을 렌더링하여 확인했습니다. 모바일의 넓은 교실은 좌석 영역에서 가로 스크롤합니다.
- Samsung Internet 실기기, 다른 브라우저, 스크린리더, EUC-KR 실제 파일은 아직 확인하지 않았습니다. 조건 탐색은 제외되었으며 PDF 검증은 아래 4단계 항목을 참고하세요.

브라우저 검증 스크립트는 `tests/browser.mjs`입니다. 개발용 Playwright와 Chromium이 있는 환경에서 `node tests/browser.mjs`로 실행합니다. Playwright가 없다면 개발 환경에서 `npm install --no-save playwright`를 실행하세요. Chromium 경로가 다르면 스크립트의 `executablePath`를 해당 경로로 수정합니다. 이 도구들은 사이트 이용자에게 필요하지 않습니다.

## 범위 변경

사용자 요청에 따라 짝 지정 기능을 제거했습니다. 좌석 색 띠·짝 번호·짝 데이터는 사용하지 않으며, 이후 단계의 짝 지정과 짝 금지 조건도 구현 대상에서 제외합니다. 좌석 제외·복원, 통로, 통로 기능은 유지합니다. 이후 사용자 요청으로 3단계의 고정석·인접 금지·구역 조건도 제외했습니다.

## 2단계 사용 방법과 확인 결과

명단 확정 후 공개 방식을 고르고 **자리 배치 시작**을 누릅니다. 5초 카운트다운 뒤 전체 공개하거나, 좌석을 눌러 하나씩 공개합니다. 공개된 좌석 두 개를 차례로 클릭·터치하거나 Tab과 Enter/Space로 선택하면 교환됩니다. 마우스 드래그와 빈자리 이동도 지원합니다. 실행 취소·다시 실행은 현재 페이지에서만 유지합니다.

취소하면 이전 결과를 유지합니다. 실행 중 교실·명단·공개 방식 변경과 중복 시작은 막습니다. 교실 설정 적용·교실 편집·새 명단 확정 시 결과와 교환 이력을 초기화합니다. 명단 미리보기는 확정하기 전까지 현재 명단을 바꾸지 않습니다. 보기 방향 전환은 실제 배치를 바꾸지 않습니다.

음악은 Web Audio의 삼각파와 점차 빨라지는 아르페지오로 직접 합성한 짧은 음악입니다. 외부 음원·음악 API는 없으며 원본 사이트 음원을 사용하지 않습니다. 음소거·볼륨·취소를 지원하고 재생 불가 시 무음으로 계속합니다. 계산은 최대 120석의 제한된 셔플과 독립 검증으로 즉시 끝내며 후보를 5초 전에 공개하지 않습니다. 조건 탐색은 사용자 요청으로 제외했습니다.

Chromium 자동 확인: 5초 전 결과 비노출, 30명 누락·중복 없는 배치, 중복 실행·편집 잠금, 키보드 교환, 실제 마우스 드래그, 빈자리 이동, 실행 취소·다시 실행, 결과 숨김, 취소 시 이전 결과 복원, 재시작과 한 자리씩 공개, 명단 재확정 시 결과 초기화 통과. 오디오 생성이 차단된 상황에서 무음 진행과 취소도 확인했습니다. 기존 1단계 검증도 통과했습니다. 화면을 렌더링하여 배치 결과를 확인했습니다.

실제 스피커 청취, Samsung Internet의 오디오 정책·터치 드래그, 전체화면 실기기 동작은 아직 확인하지 않았습니다. 터치에서는 두 좌석을 차례로 누르는 방식을 이용할 수 있습니다. 고정석·인접 금지·구역 조건은 구현 대상에서 제외했습니다.

## 4단계 PDF 직접 다운로드

배치 완료 후 제목과 A4 가로/세로를 선택하고 PDF 파일 다운로드를 누릅니다. 현재 학생/교사 보기 방향과 수동 교환 결과를 반영합니다. 숨김·한 자리씩 공개 중에도 PDF는 전체 결과를 출력합니다. 배치 전·배치 실행 중·결과 초기화 시에는 다운로드할 수 없습니다.

PDF는 브라우저에서 텍스트와 도형으로 생성합니다. 칠판·교탁·학번·이름·좌석 ID·빈자리·제외 좌석·통로를 표시하며 설정 패널과 조작 버튼은 넣지 않습니다. 긴 이름은 줄바꿈하고 글자 크기를 조절합니다. 읽기 좋은 크기로 담기 어려운 입력은 오류로 안내하며 방향 변경이나 페이지 분할을 제안합니다. 지원하지 않는 문자(예: 일부 이모지)는 오류로 알리고 잘못된 PDF를 성공으로 처리하지 않습니다. 일반 학급은 한 페이지, 큰 좌석이 필요하면 여러 페이지 옵션을 사용합니다.

확인: Chromium 직접 다운로드, A4 가로/학생과 세로/교사, 결과 숨김 상태의 전체 출력, 앞자리 0 학번·동명이인·긴 한글 이름, 수동 교환, 통로·비활성 좌석, 120석 2페이지 출력을 검사했습니다. 실제 PDF를 이미지로 렌더링해 한글과 교실 경계를 확인하고 pdffonts로 글꼴 포함을 확인했습니다. 실제 프린터·Samsung Internet 기기에서의 다운로드는 미확인입니다.

개발 검증: `node tests/pdf.mjs` (Playwright와 Chromium 필요). 검증용 PDF는 /tmp에 생성됩니다. 사이트 실행에는 별도 설치나 빌드가 필요하지 않습니다.
